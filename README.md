# Primer proyecto en Java

Este es un proyecto de ejemplo para aprender a programar en Java.

## Aplicación de Tareas
Una aplicación simple para gestionar tareas pendientes.

### Hisdtoria de Usuario
Como usuario, quiero poder agregar, eliminar y marcar tareas como completadas para poder organizar mi lista de tareas de manera eficiente.

1. **Agregar Tarea:** El usuario puede agregar una nueva tarea proporcionando un título y una descripción.
2. **Eliminar Tarea:** El usuario puede eliminar una tarea existente de la lista.
3. **Marcar Tarea como Completada:** El usuario puede marcar una tarea como completada para indicar que ya no necesita atención.
4. **Ver Lista de Tareas:** El usuario puede ver todas las tareas pendientes y completadas en una lista organizada.
5. **Editar Tarea:** El usuario puede editar el título y la descripción de una tarea existente.

## Implementación
- Java 27
- `Scanner` y `println` para la entrada y salida de datos.
- ``ArrayList`` para almacenar las tareas.
